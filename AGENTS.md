# LexicaNext

LexicaNext is an English vocabulary learning app with custom word sets and
interactive practice modes, built with React and ASP.NET Core.

To run it locally in containers, follow
[Run LexicaNext with Docker Compose](containers/README.md).

## Agent skills

### Issue tracker

Issues live in local Markdown files under `.scratch/<feature>/`.
See `docs/agents/issue-tracker.md`.

### Triage labels

Use the five default triage labels.
See `docs/agents/triage-labels.md`.

### Domain docs

Use a single-context layout with root `GLOSSARY.md` and `docs/adr/`.
See `docs/agents/domain.md`.
