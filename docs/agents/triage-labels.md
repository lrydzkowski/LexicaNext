# Triage labels

Use these canonical role names in each issue's `Status:` line.

| Role | Status value | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Needs maintainer evaluation |
| `needs-info` | `needs-info` | Needs information from the reporter |
| `ready-for-agent` | `ready-for-agent` | Ready for agent implementation |
| `ready-for-human` | `ready-for-human` | Needs human implementation |
| `wontfix` | `wontfix` | Will not be implemented |

Each triaged issue has exactly one triage state.
Record its category separately as `bug` or `enhancement`.

If the tracker vocabulary changes, update the Status value column.
